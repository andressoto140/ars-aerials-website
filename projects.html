Home Watch

Python, YOLO11, OpenCV, FastAPI, Claude API, Telegram

Private repository

Smart alerts for a Hikvision home camera system. It reads the recorder’s video streams over the home network, uses a YOLO11 model to tell people apart from ordinary motion, and sends a Telegram alert with a photo and a one-line AI description of what happened.

  • Alert zones so people walking on the street are ignored
  • Quiet hours, with events still saved
  • A local dashboard listing every detection
  • A daily summary sent each evening

Trading Bot

Python, alpaca-py, yfinance, pytest

Private repository

An automated moving-average crossover strategy on an Alpaca paper-trading account. Each weekday at market open it downloads 100 days of prices, compares the 20-day and 50-day averages, and places an order only on a true crossover.

  • Settings in a config file, API keys kept out of the code
  • Dry-run mode that logs decisions without trading
  • Unit tests for the strategy logic
  • Runs on a schedule with Windows Task Scheduler and writes daily logs

Framing Takeoff

JavaScript, HTML, CSS

An estimating tool for a family-owned wood framing company, built to replace hand-written quotes. It turns a job’s measurements into a material takeoff and a priced quote the office can send.

  • Saves estimates so they can be reopened and edited
  • Exports a quote for the customer and a lumber list for the supplier

Local sales route planner

Node.js, ExcelJS, HTML

Tools for my NFC review-card side business. I gathered 137 local businesses with 75 or fewer Google reviews, scored them as leads, and generated weekday and weekend driving routes.

  • Phone-friendly route pages with one-tap Google Maps directions
  • An Excel tracker with dropdowns and sales totals that update themselves
